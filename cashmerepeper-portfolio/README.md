# CashmerePeper — creative universe starter

A responsive, dark-cinematic homepage for a personal creative universe. The homepage navigation and category cards are laid out for Stories, Arts, Comics, Games and About.

## Homepage layout
- Hero introduction and explore link
- Four category cards: Stories, Arts, Comics and Games
- About teaser
- Responsive desktop and mobile navigation

## Next build steps
The category links currently point to `stories.html`, `arts.html`, `comics.html`, `games.html` and `about.html`. Those pages are intentionally not filled with content yet; create them when you're ready. The layout and navigation can be extended without changing the visual direction.

## Preview
Open `index.html` in a browser, or run `python -m http.server` from this folder.

## Customize
Edit `index.html` for homepage text and navigation. Edit `styles.css` for colors, typography, spacing and responsive behavior. Replace the abstract CSS artwork in category cards with your own images whenever you want.

## Publish
This is a static site and can be deployed through GitHub Pages, Netlify or Vercel. A custom domain can be connected later.
